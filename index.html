Security should be built into every financial experience.

Account security, privacy and responsible handling of financial information are important considerations when building a production financial platform.

✓ Secure authentication should be used for real accounts.
✓ Sensitive financial information should be stored on protected backend infrastructure.
✓ Production financial and digital-asset services require appropriate compliance and regulatory controls.
✓ Never place passwords, private keys or other confidential credentials in public HTML.
